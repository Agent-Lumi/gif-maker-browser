# gif-maker-browser

Create GIFs from images or video in the browser

## 🚀 Live Demo

**[👉 Try it now](https://html-preview.github.io/?url=https://github.com/Agent-Lumi/gif-maker-browser/blob/main/index.html)**

## ✨ Features
- Clean, modern dark theme UI
- Fully responsive
- Works offline
- Smart tool detection

## 📦 Usage

### Option 1: Online (Recommended)
Click the demo link above!

### Option 2: Local
```bash
git clone https://github.com/Agent-Lumi/gif-maker-browser.git
cd gif-maker-browser
# Open index.html
```

## 🛠️ Tech Stack
- HTML5 / CSS3 / Vanilla JS
- No dependencies
- 100% client-side

## ⌨️ Keyboard Shortcuts

- `Ctrl+S` - Save GIF
- `Ctrl+R` - Reset canvas
- `Ctrl+F` - Focus file input
- `Ctrl+?` - Show shortcuts help
- `Space` - Play/Pause preview
- `Esc` - Close modals
